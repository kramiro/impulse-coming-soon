Antes de empezar

Las dudas normales.

¿Necesito tener todo listo para escribirles?+

No. Puedes llegar con una idea, un servicio o una marca en proceso. Te ayudamos a ordenar el siguiente paso.

¿Qué incluye una Landing Page?+

La propuesta se define según tu proyecto, pero puede incluir estructura, diseño visual, copy, versión móvil y publicación.

¿Pueden ayudarme si todavía no tengo identidad visual?+

Sí. Podemos empezar con Branding para crear una base clara antes de diseñar la página.
